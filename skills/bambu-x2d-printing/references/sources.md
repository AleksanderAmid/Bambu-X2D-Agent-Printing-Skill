## Design and verification decisions

- **Measure the actual feature.** The CADTests researchers use executable geometry/topology tests derived from the prompt. A comparison of a pocket depth, pitch or count can catch a correct-looking near miss. CADSmith combines kernel measurements and visual inspection to address different errors. The procedure draws on these studies. The authors evaluated their own systems. [CADTests](https://arxiv.org/abs/2605.07807) · [CADSmith](https://arxiv.org/abs/2603.26512) · [Agent CAD design with visual feedback](https://www.cambridge.org/core/journals/proceedings-of-the-design-society/article/from-text-to-design-a-framework-to-leverage-llm-agents-for-automated-cad-generation/5BD8D63CFCED28BDD7A01313162FFBE7)
- **Keep an editable master.** Use constrained dimensions and a valid recomputed BRep for fitted parts. Check geometry after modeling and control tessellation at mesh creation. In Blender evaluate transforms/modifiers and export the intended selection before doing an independent readback. [FreeCAD geometry checks](https://github.com/FreeCAD/FreeCAD-documentation/blob/main/wiki/Part_CheckGeometry.md) · [FreeCAD mesh from shape](https://github.com/FreeCAD/FreeCAD-documentation/blob/main/wiki/Mesh_FromPartShape.md) · [Blender STL options](https://docs.blender.org/manual/en/5.3/files/import_export/stl.html) · [Blender 3D Print Toolbox](https://extensions.blender.org/add-ons/print3d-toolbox/)
- **Preserve units and instances.** The 3MF root unit and component/build transforms determine printed placement and size. glTF uses metres. STL records triangular coordinates and needs external unit context. Reopen the actual export at known scale. [3MF core](https://github.com/3MFConsortium/spec_core/blob/master/3MF%20Core%20Specification.md) · [glTF specification](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html) · [STL format family](https://www.loc.gov/preservation/digital/formats/fdd/fdd000504.shtml)
- **Calibrate critical fits.** Clearance varies with part geometry, build direction, material and process. Use a real mating sample for consequential fits. Use clearance data from a different printer as a starting point for an X2D coupon. [Prusa design-for-printing guide](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)
- **Slice for the active tool combination.** Bambu publishes different build envelopes and feed systems for the X2D heads. Validate the actual per-nozzle region and support/tower assignments. Inspect the layer preview and the final selected plate in the operator interface. [X2D specifications](https://blog.bambulab.com/xcellence-made-simple-bambu-lab-presents-the-x2d/) · [Extrusion systems](https://blog.bambulab.com/two-extruders-one-purpose-what-is-x2d-direct-drive-extrusion-and-auxiliary-extrusion/) · [X2D user manual, chapter 5](https://csm.bblcdn.com/hub/7c58718aaa2e40edab56efb87419a96a.pdf) · [Studio CLI](https://github.com/bambulab/BambuStudio/wiki/Command-Line-Usage)
- **Ground the design loop in saved artifacts.** Kiln demonstrates revision-aware agent design/slice workflows. The installed Bambu connector provides upstream fitting and after-slice prompts plus read-only inspections. Borrow the revision and evidence practices. This skill's actual commands target the installed servers. [Kiln](https://github.com/codeofaxel/Kiln) · [Bambu connector](https://github.com/DMontgomery40/bambu-printer-mcp)
- **Keep decisions and tools discoverable.** Load a small entry point and only the guide relevant to the job. Test observable outcomes and tool choices together. Reserve a human decision for the particular physical start.
